# HH SFW

Trying to make HH SFW 😅

## Install

Install from here: https://sleazyfork.org/fr/scripts/565232-hentai-heroes-sfw

Or by using the direct link: https://raw.githubusercontent.com/GetoHH/HH-SFW/refs/heads/master/hh-geto-sfw-script.js

You need [TamperMonkey](https://www.tampermonkey.net) or a similar browser extension.

## Main Features

- removing explicit images
- removing girl avatar images
- removing player avatars
- setting all girl icons to the default one
- changing game background to have a SFW one


### Additional setting in order to fully block the login page images

You need to:
- install the "**uBlock Origin**" extension
- go to "**My filters**"
- check "**Enable my custom filters**"
- copy/paste the following line in the editor:

`
||images.hh-content.com/eggs/authentication
`
- press "**Apply**"
